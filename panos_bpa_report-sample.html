#213 Device Setup Session Global None
Global Packet Buffer Protection and its thresholds should be enabled in the Session Settings.
Global Packet Buffer Protection (PBP) protects the firewall buffers from single-session denial-of-service (DoS) attacks, from attacks from a single source IP address, and from source IP addresses that create many small sessions that combine to consume packet buffers. Global PBP applies Random Early Detection (RED) to drop some of the traffic, which prevents these types of DoS attacks from consuming the firewall packet buffer resources and denying service to legitimate users. However, global PBP does not discard or block offending traffic. All thresholds must contain non-zero values because the value "0" means the threshold or timer is not applied. (In addition to global PBP, enabling per-zone PBP protects firewall buffers on a per-ingress-zone-basis and can discard or block offending traffic.) PBP also protects you against misconfigured internal devices, faulty NIC adapters, and insider threats.
